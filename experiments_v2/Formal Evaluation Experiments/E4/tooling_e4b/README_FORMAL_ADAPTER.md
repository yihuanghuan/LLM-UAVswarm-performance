# E4B formal exact-trial adapter

`e4b_formal_adapter.py` accepts one globally supplied registered trial and never owns campaign order or journal state. Formal execution remains behind the external launch gate. `spec_rehearsal` reconstructs all sealed timing, allocation, profile, authority-predicate, and logging fields without physical scientific execution.

`e4b_engineering_smoke.py` uses `ENG-E4B-AUTHORITY-TRACE-4UAV-v1`, a non-registered engineering fixture, to exercise the frozen PX4/ROS/LADRC/IAPF command and evidence-retention path. It is not scientific evidence and cannot create an accepted formal result.
