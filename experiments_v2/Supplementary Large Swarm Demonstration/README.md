# Supplementary Large-Swarm System Demonstration

This directory is separate from the closed E5-v2 formal campaign. It contains
engineering infrastructure validation and prospective supplementary visual
demonstration design only. Infrastructure sweeps are not scientific missions,
are not formal results, and never enter the E5-v2 denominator.

The production method remains the `paper-final-sim-v3` method at
`6cf402debf23851b1eff3edc6f3ab49eae7127c4`, with production policy SHA-256
`6b47d27f4253d7311e79ea51f6dd1cf0d0182e6df24374a94abae0aa6a135858`.

Allowed interpretation is limited to the largest successfully tested
supplementary infrastructure configuration and, after separate authorization,
qualitative system demonstration. This study does not establish formal or
asymptotic scalability, arbitrary-N generalization, causal N effects, or a new
core paper contribution.
