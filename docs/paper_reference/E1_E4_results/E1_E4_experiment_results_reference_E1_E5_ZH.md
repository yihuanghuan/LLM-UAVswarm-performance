# E1 — 不发生过早物理承诺的语义落地

## 研究问题与必要性

E1 测试冻结的候选语义接口是否能编码注册命令的预期任务语义，同时让状态依赖的中心、尺度和时序量保持符号形式，直到运行时获得解析所需信息。相关失败模式是**过早数值承诺**：在相应运行时状态或策略尚不可用时，语言解释阶段就把注册的未解析 `c`、`r` 或 `T` 字段替换为数值。[来源：`E1-PROTOCOL`；`E1-REGISTRY`。]

E1 是必要的，因为如果面向语言的表示丢失请求的任务，或强迫每个请求变成早期数值形式，延迟绑定架构就没有价值。反过来，仅有准确的语义提取也不能证明在物理状态变化时延迟解析有意义。因此 E1 评估贡献 1 的语义部分；承诺时机的物理后果留给 E2。

这是有限的候选注册表评估，不是开放世界自然语言理解基准。命令、预期有效性标签、拒绝类别、真值 Candidate Missions、类别分布、模型配置与随机化推理顺序，都在被接受的正式运行前冻结。[来源：`E1-REGISTRY`；`E1-DATA`；`E1-ORDER`；`E1-MANIFEST`。]

## 数据集与正式协议

**事实——总体。** 封存数据集含 120 条命令：96 条预期有效、24 条预期无效。正式审计恢复了恰好 120 条终态命令记录，并通过封存分母、终态集合、推理顺序、尝试保留、重试记账、来源及工作树检查。没有命令以基础设施失败结束。[来源：`E1-REGISTRY`；`E1-AUDIT`；`E1-MANIFEST`。]

96 条有效命令有意分布于各语义维度，而非被视为同质提示集合：

| 注册的有效命令维度 | 冻结分布 |
|---|---|
| 任务结构 | single 72；sequential 12；parallel 12 |
| 中心语义 | absolute 24；relative 24；auto 24；mixed 24 |
| 尺度语义 | explicit 15；compact 15；normal 14；spacious 14；auto 14；mixed 24 |
| 时序语义 | explicit 36；auto 36；mixed 24 |
| 运动风格 | smooth 24；normal 24；aggressive 24；mixed 24 |
| 安全语义 | numeric 54；qualitative-safer 18；mixed 24 |
| 过渡 | direct 60；continuous 12；hover-and-wait 24 |

[全部计数的冻结来源：`E1-REGISTRY`。]

24 条无效命令均分为六个冻结的预期拒绝类别：指令不完整、语义矛盾、无人机 ID 不可用、编队语义违规、非法过渡和不支持/歧义语义，每类四条命令。运行后不得根据模型文字重新标记预期类别。只有经过重试策略后，没有可执行 Candidate 能通过注册的解析、schema、可用性、语义、任务编译和派发前验证门禁时，命令才计为被拒绝。后续飞行行为与 E1 无效命令拒绝无关。[来源：`E1-PROTOCOL`。]

**事实——提供方与尝试结构。** 一条**命令**是一个注册输入，在 120 条命令的终态分母中仅贡献一次。一次**提供方尝试**是解析器重试策略下的一次模型调用。因此一条命令可产生一次、两次或三次提供方尝试，但仍只有一条终态记录。被接受的正式运行对 120 条命令进行了 163 次提供方尝试：162 次返回模型响应，一次抛出提供方异常。冻结模型为 `MiniMax-M2.7-highspeed`，temperature 为 0.0、top-p 为 0.01、最大补全 token 数为 4,000、响应格式为 JSON-object，每条命令最多三次尝试。[来源：`E1-MANIFEST`；`E1-AUDIT`。]

在封存随机排列中进入下一条命令前，必须先完成当前命令的重试。每次尝试均被保留；禁止手动删除、手动重跑命令及第二个正式批次，审计确认这些行为均未发生。[来源：`E1-PROTOCOL`；`E1-ORDER`；`E1-MANIFEST`。]

## 注册指标与评分语义

E1 的主要指标固定如下。[来源：`E1-PROTOCOL`。]

1. **有效命令 schema 接受率：**预期有效命令产生 schema 有效 Candidate Mission JSON 的数量，除以 96。
2. **语义字段准确率：**任务字段 `U,F,c,r,T,m,s,q` 的准确率与逐命令任务关系准确率的宏平均。任务字段的分母是任务实例而非命令：96 条有效命令包含 120 个任务实例，因为顺序与并行命令包含多个任务。任务关系仍为命令级，分母为 96。这解释了 `score.json` 中表面上的 120 与 96 分母差异；它不是来源冲突。[交叉核验：清单中的 `E1-SCORE`；`E1-DATA`；`E1-SCORER`。]
3. **精确语义任务准确率：**对每条预期有效命令，完整归一化 Candidate Mission 相等的数量，除以 96。归一化只规范化注册等价关系，例如 JSON 键顺序、整数/浮点数等价、无人机集合顺序和并行任务顺序；不修复缺失、多余、schema 无效或语义错误字段。
4. **无效命令拒绝率：**在各不可变预期类别下正确终态拒绝的数量，除以 24。
5. **过早数值承诺：**未解析的 relative/maintain-current/auto 中心、qualitative/auto 尺度或 auto 时序字段被错误替换为数值的数量，除以全部注册的未解析机会。定性 safer/cautious/conservative 安全语义冻结为 `s=1.0`，明确不计为过早承诺。
6. **延迟：**每次尝试的提供方调用墙钟延迟，以及命令至终态的总延迟，以中位数和注册的高位百分位数汇总。
7. **次要诊断：**严格 JSON 格式合规、重试分布、拒绝类别混淆以及按注册类别划分的精确准确率。

## 解释与边界

**解释——支持。** 候选语义接口以 schema 有效、归一化任务语义精确正确的形式表示了全部 96 条注册有效命令，并保留了全部 225 个注册未解析数值机会。在这一有限数据集中，证据有力支持语义侧命题：未解析物理值可以保持符号形式，而不丢失预期有效任务。

**解释——不支持。** E1 不支持一般意义上的可靠无效命令拒绝、稳健非法过渡拒绝、稳定严格 JSON 提供方行为、开放世界语言理解、一般语言能力或相对其他接口的优越性。19/24 的无效结果和 0/4 的非法过渡结果直接制约过宽主张；0/162 的格式合规观测也使得在这一确切提供方/配置下，原生可靠严格结构化输出的主张无法成立。

E1 也不证明延迟承诺的物理收益。零过早承诺结果确定了语义边界上哪些内容保持未解析，但 E1 没有操纵执行状态变化。E2 提供配对的物理时机证据。

**论文写作建议。** 可表述为：“在冻结的 120 条命令候选语义注册表上，全部 96 条有效命令得到精确表示，225 个注册未解析机会中没有发生过早数值承诺；无效拒绝不完整（19/24），包括 0/4 的非法过渡拒绝。”保留“候选”“冻结注册表”和无效拒绝限定。

## 建议的论文呈现

- **主文紧凑表格：**数据集规模；96/96 schema 接受；96/96 精确任务准确；0/225 过早承诺；19/24 无效拒绝；0/4 非法过渡拒绝；0/162 严格格式合规；以及 163 次尝试/120 条终态命令。该表同时展示优势与失败。
- **主文文字：**解释命令与提供方尝试的区别，说明 24 条命令需要重试。若延迟属于论文系统叙事的一部分，可提及命令至终态延迟中位数；否则把完整百分位行放在补充材料。
- **补充材料：**完整类别分布、逐类无效混淆矩阵、完整提供方/命令延迟百分位数、token 诊断、归一化契约、推理排列和重试记账。
- **不必绘图：**每个注册类别的精确准确率。所有类别都是 100% 时，大图相较紧凑陈述和补充表格几乎不增加信息。

# E2 — 早期承诺与信息对齐的延迟承诺

## 研究问题与必要性

E2 测试**物理承诺时机**的因果后果，而非语言准确性。两种条件收到相同的冻结 Candidate 语义和英文命令；E2 仅改变未解析中心/尺度/时序字段是在解析时快照上数值解析，还是保持符号形式直到注册的执行时快照与运行时阶段。[来源：`C2-RAW-E2`。]

相关失败模式是陈旧承诺。如果状态在解释之后、执行之前发生变化，早期数值可能不再描述预期的状态相对几何或可行时序。延迟数值则可纳入执行快照。E2 是必要的，因为不能仅从 E1 的语义正确性推断这一物理后果。

## 实验设计

**事实——配对总体。** E2 包含 120/120 次科学完整尝试，没有基础设施失败。它们构成 60 对 Early/Late 比较。其中三十对为 `SHIFT`，三十对为 `NO_SHIFT`；等价地，六个场景中的每一个为每种状态条件贡献五个种子，每个场景/状态/种子配对中都有两种承诺条件。[来源：`E2-SUMMARY`；`E2-ATTEMPTS`；`C2-RAW-E2`。]

条件如下：

- **早期承诺（Early Commitment）：**在解析时快照上解析 `c/r/T`，只把这些字段替换成 absolute/explicit 数值，并保留该请求用于执行。冻结可行性门禁保持启用，可能提高早期显式时长；这种提高计为修正。
- **信息对齐的延迟承诺（Information-Aligned Late Commitment）：**保留未经修改的 Candidate，包括 relative/maintain-current/auto 中心、qualitative/auto 尺度和 auto 时长，直到冻结生产运行时使用执行时状态解析它们。

不变字段为任务 ID、无人机集合、编队、运动风格、安全值和过渡。提示、schema、语义解释、配对内运行时状态、种子、策略、分配器和控制器均禁止不同。解析快照相同，执行时点在两秒之后；`NO_SHIFT` 执行快照除时点外与解析快照相同。`SHIFT` 在捕获执行快照前应用确定性的注册状态算子。[来源：`C2-RAW-E2`。]

六种场景机制旨在暴露不同的未解析量：

| 场景 | 未解析字段 | 注册偏移的作用 |
|---|---|---|
| E2-RSV-01 | 中心、尺度、时长 | 平移全部参与者；运行时状态平移测试 |
| E2-PES-01 | 相对中心、尺度、时长 | 用不同的世界坐标向量平移全部参与者 |
| E2-RC-01 | 相对中心、尺度 | 隔离的相对中心落地 |
| E2-QS-01 | 定性尺度 | 绝对中心/显式时长下的尺度不变性对照 |
| E2-AT-01 | 自动时长 | 将参与者移得更远离固定目标；可行性/时序更新 |
| E2-DF-01 | 中心、尺度、时长 | 设计为需要动态可行性修正的非均匀状态偏移 |

[冻结来源：`C2-RAW-E2`。]

## 解释与边界

**解释——支持。** 当相关执行状态变化时，在测试案例中，解析时数值承诺变得陈旧或需要注册可行性修正。将未解析意图保留到执行快照，消除了匹配 Late 案例中全部观测到的状态一致性违规、动态不可行和修正。状态不变时，两种条件均没有不良时机结果。这种模式支持信息可用性机制，而非某一条件无条件占优。

两种条件都没有拒绝这一点很重要：Late 的优势不是通过拒绝困难请求获得的，Early 也仍产生可执行落地。结果涉及执行内容的一致性与可行性，而非 Candidate 是否能够变为可执行。

**解释——与 E1 的联合作用。** E1 表明候选表示可让状态依赖量保持符号形式，同时保留预期任务语义。E2 表明这些量的解析时机为何具有物理意义。二者共同对贡献 1 的支持强于任一单项实验：E1 回答**什么应保持未解析**，E2 回答**为什么信息对齐的解析时机重要**。

**解释——不支持。** E2 不表明延迟绑定普遍最优、每次早期承诺都错误、每种状态变化都会损害早期承诺、延迟承诺改善所有可能指标，或测试策略对机器人规划全局最优。E2 的边界为六个注册离线封装场景、确切确定性状态算子、冻结分配器/可行性策略和所评估的不良结果。E2 也不比较替代语言模型或语义接口。

**论文写作建议。** 以状态变化和承诺时机的交互为主线：“在 30 对偏移配对中，Early 产生 25 次状态一致性违规和 15 次不可行/修正结果，Late 则均为零；在 30 对无偏移配对中，两种条件均无不良时机结果。”然后解释同命令/同语义控制。避免只呈现全部配对比率，因为合并偏移与无偏移配对会掩盖机制。

## 建议的论文呈现

- **主文：**使用紧凑的 SHIFT/NO_SHIFT × Early/Late 表格或分组点图/柱图，展示状态不一致与修正/不可行。包含确切计数和配对 N；若空间允许，使用冻结配对置信区间。
- **主要文字：**一句确立 120/120 完整、60 对以及可执行落地/拒绝不变；一句解释结果集中于状态变化。
- **补充材料：**逐场景分解、完整配对差数组、Cohen's dz、全部注册结果，以及确切场景算子/解析值。
- **避免：**合并 SHIFT 与 NO_SHIFT 的图。它会使因果时机机制看起来比注册设计更弱、更不具体。

# E3-v4 — 规划–执行安全分解

## 研究问题与历史背景

E3-v4 问两类不同的安全风险是否需要两种不同职责：规划是否应消除从已承诺几何与分配中可预测的风险，闭环反馈是否应减少因执行偏离已承诺计划而只在规划后出现的风险。贡献层级问题不是是否存在两个软件模块，而是被独立操纵的职责是否产生预期的、机制特异的安全效应。[来源：`E3-REGISTRY`；`E3-CONTRACT`；`E3-REPORT`。]

历史 E3-v3 检验保持不可变，但不是论文关于反馈侧的主要确证证据。其原始残余风险操纵未能可靠诱发注册的 F0 残余风险状态，混合风险案例也未保留足够的规划后残余风险以辨明反馈职责。因此 E3-v4 围绕确定性规划后执行偏差单独重新设计、预注册、封存、激活，作为独立的 360 次尝试实验活动运行，并按冻结契约分析。E3-v3 的任何观测均未与 E3-v4 合并。[来源：`E3-REGISTRY`；`E3-REPORT`。]

这段历史应描述为检验辨识问题，而非“失败的科学结果”。原操纵没有实例化评估注册反馈侧对比所需的状态；E3-v4 修正了检验，同时保留问题，并在正式执行前冻结新设计。

## 正式 2×2 设计

规划因子为：

- **P0：**仅距离基线分配（`distance_hungarian`）。
- **P1：**安全感知分配（`safety_aware`）。

反馈因子为：

- **F0：**关闭反馈避障。
- **F1：**开启 IAPF dual 反馈避障（`iapf_dual`），使用冻结逃逸模式与滤波参数。

因此四个单元为 P0_F0、P0_F1、P1_F0 和 P1_F1。不允许按条件调参。在注册区组内，运行模式、LADRC 加速度控制模式、策略、normal 运动风格、安全乘子、direct 过渡、场景几何、种子和相关执行规则均保持固定。[来源：`E3-REGISTRY`。]

操纵族隔离风险机制：

| 族 | 风险机制 | 场景 | 目标职责 |
|---|---|---|---|
| A — 可预测结构风险 | 分配/路径冲突在规划时可见；不注入规划后偏差。 | E3-A-01，四机分配冲突目标集；E3-A-02，八机反向圆形目标集 | 规划，P1 对比 P0 |
| B — 残余执行风险 | 名义规划输入不含注册结构冲突；确定性命令延迟或参考偏差仅在规划承诺后引入，并排除于规划器预测之外。 | E3-B-01，0.4 s 命令延迟；E3-B-02，从 3.5 s 开始持续 3.0 s 的 1.5 m 参考偏移 | 反馈，F1 对比 F0 |
| C — 混合、空间隔离风险 | 可预测结构子系统与规划后残余风险子系统共存于空间分离的无人机子集中。 | E3-C-01 将 A-01 结构与 B-01 时序偏差结合；E3-C-02 将 A-01 结构与 B-02 风格参考偏差结合 | 两种职责及其交互 |

[冻结来源：`E3-REGISTRY`。]

**事实——注册设计。** 六个固定场景、15 个注册配对种子和四个析因单元产生 360 个注册槽位：

\[

\]

重复测量区组为 `b = (scenario, seed)`。一个主要区组必须在四个单元中各有恰好一次科学合格尝试。共有 90 个注册区组，即每族最多 30 个区组。同一族中的两个场景构成固定分层。区组内相关的简单对比不被当作独立观测。[来源：`E3-REGISTRY`；`E3-CONTRACT`。]

**事实——最终记账。** 全部 360 个槽位按冻结顺序消耗。实验活动产生 343 次科学成功尝试和 17 次基础设施失败，没有其他状态、替代尝试或额外样本。七十四个区组含四次科学成功；16 个区组不完整，其中一个区组有两个失败单元。因此主要完整区组总体为 74 个区组、296 次尝试。属于不完整区组的 47 个成功单元仍可用于敏感性/描述汇总，但从每项主要析因对比中排除。[来源：`E3-COMPLETION`；`E3-REPORT`；`E3-SUMMARY`。]

## 主要端点与析因估计目标

主要安全端点是实际成对硬风险暴露，

\[
J_{\mathrm{hard}}=\sum_{i<j}\int \mathbf{1}\!\left[d_{ij}(t)<d_{\mathrm{hard}}\right]\,dt,
\qquad d_{\mathrm{hard}}=1.50\ \mathrm{m},
\]

以 pair-seconds 报告。每个无序对贡献其测量 3-D 间距严格低于硬阈值的时长；等于阈值不属于风险。`J_hard` 越低越安全。逐对阈值交叉采用线性插值，并对各对时长求和。相关事件计数按每一对分别计算低于阈值的极大连通区间数。[来源：`ANALYSIS-SEMANTICS`；`E3-CONTRACT`；`E3-REPORT`。]

对于完整区组 `b` 中的端点 `Y`，冻结估计目标为：

\[
\Delta_P^{(b)}=
\frac{(Y_{P1F0}-Y_{P0F0})+(Y_{P1F1}-Y_{P0F1})}{2},
\]

\[
\Delta_F^{(b)}=
\frac{(Y_{P0F1}-Y_{P0F0})+(Y_{P1F1}-Y_{P1F0})}{2},
\]

\[
\Delta_{PF}^{(b)}=
(Y_{P1F1}-Y_{P1F0})-(Y_{P0F1}-Y_{P0F0}).
\]

`Delta_P` 在两个反馈水平上平均区组内 P1 减 P0 的规划效应。`Delta_F` 在两个规划水平上平均区组内 F1 减 F0 的反馈效应。`Delta_PF` 是不同规划水平之间反馈效应的差，等价于端点尺度上的规划与反馈交互。对暴露、事件、二元风险、failsafe 和近限比例而言，负值更安全；对最小间距和任务成功而言，正值更安全。[来源：`E3-CONTRACT`。]

连续/计数估计是区组对比的均值，采用按场景分层的配对区组百分位 bootstrap 双侧 95% 区间，重采样 10,000 次。二元析因效应使用相同区组级风险差对比和 bootstrap 结构；单元比例使用 Wilson 区间。这些方法和重采样种子是冻结输出，此处不重新计算。[来源：`E3-CONTRACT`；`E3-FACTORIAL`；`E3-BINARY`。]

# E4A — 运动风格的行为可区分性

## 研究问题与必要性

E4A 问在高优先级任务与安全包络保持固定时，有界语义风格——smooth、normal 和 aggressive——是否产生可测的底层闭环行为差异。失败模式是语义装饰：风格标签可出现在接口中，却没有物理作用。E4A 测试行为后果，而非权限保持。[来源：`C2-RAW-E4`；清单中的 E4A 主张裁决。]

预注册主张有意弱于普遍有序动态。预期 smooth 比 aggressive 使用更少控制努力和更低加速度峰值/RMS，aggressive 则倾向更短稳定时间。预期 normal 通常居中，但不要求它在每个场景或指标上都严格位于 smooth 与 aggressive 之间。跟踪 RMSE 被注册，但没有普遍单调方向要求。[来源：`C2-RAW-E4`。]

## 设计与固定量

**事实。** E4A 包含 45/45 次科学完整尝试，没有基础设施失败。三个场景 × 五个种子 × 三种风格构成 15 个匹配的 smooth–normal–aggressive 三元组。每种风格有 15 次尝试；每个场景有 15 次尝试。[来源：`E4A-SUMMARY`；`E4A-ATTEMPTS`。]

三种机动使用共同的四机直线编队，位移几何不同：

| 场景 | 注册位移 | 范数 | 显式时长 | 种子 |
|---|---:|---:|---:|---:|
| E4A-HORIZONTAL | [0, 4, 0] m | 4.0000 m | 4.0 s | 5 |
| E4A-VERTICAL | [0, 0, 3] m | 3.0000 m | 3.5 s | 5 |
| E4A-DIAGONAL-3D | [3, 4, 2] m | 5.3852 m | 4.0 s | 5 |

[冻结来源：`C2-RAW-E4`；5.3852 是注册值 5.385164807134504 m 的舍入呈现。]

注册底层指标为：

- **控制努力：**在 `[t0, t0 + T_explicit]` 内，对命令加速度 3-D 范数积分，再取逐机均值；单位为 m/s。
- **加速度峰值：**显式时长区间内各无人机命令加速度峰值的均值，单位 m/s²。
- **加速度 RMS：**同一区间内无人机等权合并、时间加权的命令加速度 RMS，单位 m/s²。
- **加速度上升时间：**从逐机全局峰值的插值 10% 到 90% 的时间，在全部无人机有效时取均值；不平滑。
- **跟踪 RMSE：**显式时长区间内无人机等权合并的跟踪误差 RMS，单位为米。
- **稳定时间：**无人机进入稳定悬停的最晚时间减 `t0`；与其他连续指标不同，它不在显式时长处截断。

| 加速度 RMS | 11 | 15 |
| 跟踪 RMSE | 15 | 15 |
| 加速度上升时间 | 5 | 15 |
| 稳定时间 | 6 | 13 |

[冻结来源：`E4A-SUMMARY`。“之间”是居中排序诊断，不为每项指标强加期望方向。]

因此 normal 条件在强度和跟踪量上经常居中，但在时间动态上并非如此。上升时间只在 5/15 个三元组中居中，稳定时间只在 6/13 个联合可评估三元组中居中。这直接反驳对每种响应特征笼统声称 `smooth < normal < aggressive`。

## 解释与边界

**解释——部分支持。** 在共享相同名义参考时，冻结风格产生了控制强度、加速度行为和跟踪特性的可测变化。这排除了风格标签在测试机动中仅是装饰的说法。结果支持**行为可区分性**。

结果不支持严格有序动态。控制努力与加速度量提供有力的 smooth 至 aggressive 强度对比，但上升和稳定行为没有普遍单调排序。跟踪 RMSE 在这些三元组中一致变化，但它未被预注册为必须具有普遍风格方向，不应据此事后重新定义“aggressive”。

**解释——不支持。** E4A 不表明某风格普遍更好、smooth 总能最小化每个动态量、aggressive 总是更快稳定，或 Normal 总是居中。它也不确立风格不能凌驾高优先级约束；E4B 测试这一独立性质。

**论文写作建议。** 使用“行为可区分”，而非“严格有序”。强调三个强度端点和跟踪 RMSE，然后披露上升/稳定排序较弱且不普遍。保留部分支持裁决：物理效应命题获得支持，而更强的跨指标方向模式未获支持。

## 建议的论文呈现

- **主文：**对控制努力、加速度峰值、加速度 RMS 和跟踪 RMSE 绘制配对 smooth 至 aggressive 效应图，带冻结 95% 区间。若不同单位使共享轴不便，使用紧凑统一布局并明确分开的数值标注，而不是归一化掉单位。
- **主要文字：**45 次尝试、15 个三元组、精确参考一致性和四项最易解释的配对差。包含一句说明稳定/上升排序不普遍。
- **补充材料：**全部六个端点、normal 居中计数、场景特异效应、风格级描述汇总与逐三元组配对值。
- **避免：**在视觉上暗示每项指标都单调的三风格排序图。

# E4B — 优先级 / 权限保持

## 研究问题与必要性

E4B 问低优先级运动风格偏好是否仍受显式任务、动态可行性、硬安全、时序、运动限制及控制器权限约束。失败模式是未授权越权：风格改变或绕过属于更高优先级层的决策。[来源：`C2-RAW-E4`。]

E4B 是必要的，因为仅有行为表达还不够。风格机制可产生明显不同运动，却仍不可接受，例如 aggressive 绕过可行性时序或改变硬安全归属。因此 E4B 测试贡献 3 中约束优先的部分。

## 设计与注册权限检查

**事实。** 全部 60 次正式尝试均科学完整，没有基础设施失败。四个场景 × 五个种子 × 三种风格产生每场景 15 次尝试、每风格 20 次尝试。[来源：`E4B-SUMMARY`；`E4B-ATTEMPTS`；`C2-RAW-E4`。]

| 场景 | 测试的权限冲突 | 注册要求结果 |
|---|---|---|
| E4B-FEASIBLE-EXPLICIT-T | 可行显式任务时序与风格 | 每种风格的 `T_exec` 均保持恰好 4.0 s |
| E4B-INFEASIBLE-EXPLICIT-T | 不可行请求 1.5 s 与动态可行性 | 运行时将 `T_exec` 提高到至少冻结 `T_min = 2.8844991406148166 s`；风格不能绕过速度/加速度/jerk 可行性 |
| E4B-AUTO-T | 风格可影响自动时序 | 风格特异 `T_exec` 仍不低于同一冻结 `T_min` |
| E4B-SAFETY-ACTIVE | 风格偏好与活跃分配/反馈安全 | 风格不改变 `d_hard` 或安全归属，不能绕过或禁用硬安全机制 |

[冻结来源：`C2-RAW-E4`。]

冻结层级为：

\[
\text{硬安全} > \text{动态可行性} >
\text{可行显式任务要求} >
\text{软运动风格偏好}.
\]

每次尝试生成六行权限谓词：可行显式时长保持；动态可行性与 `T_min` 保持；自动 `T_min` 保持；硬安全归属保持；运动限制与控制器钳制保持；风格之上的优先级不变。策略字段的确定性容差为 `1×10^{-9}`；物理限制使用冻结限制/饱和证据检查。只有未授权越权计数为零，且每项适用决策遵守完整层级时，尝试才计为优先级保持。缺失谓词证据不能进入分子，但仍留在分母。[来源：`C2-RAW-E4`；`ANALYSIS-SEMANTICS`。]

## 结果

| 权限结果 | 冻结观测 | 冻结描述性 95% Student-t CI |
|---|---:|---:|
| 总体优先级保持 | **60/60 = 1.0000** | [1.0000, 1.0000] |
| 未授权越权 | **0/60 次尝试；总计数 0** | 不是单独的比例区间 |
| 按场景 | 四个场景各 15/15 | 各为 [1.0000, 1.0000] |
| 按风格 | smooth 20/20；normal 20/20；aggressive 20/20 | 各为 [1.0000, 1.0000] |

[冻结来源：`E4B-SUMMARY`；逐行交叉核验：`E4B-ATTEMPTS`。区间是冻结描述性 t 区间，不得用新计算的二项区间替换。]

详细权限输出包含 360 行谓词，每次尝试六行。全部 360 条谓词记录有效，并在冻结评分器下标记为通过；225 条适用于相应场景/尝试上下文，没有适用检查失败。[来源：`E4B-CHECKS`；计数是冻结行的直接审计聚合，不是新的统计分析。]

## 解释与边界

**解释——支持。** 在 60 次注册权限冲突尝试中，软风格没有越过所测试的高优先级约束。可行显式时序保持固定，不可行/自动时序遵守动态下界，硬安全归属不变，执行配置保持在冻结运动/控制器限制内。[来源：E4B 主张裁决；`E4B-SUMMARY`；`E4B-CHECKS`。]

**解释——不是形式保证。** 观察到 60/60 优先级保持不证明权限永远不会被违反。结果限于四个注册场景、三种风格、五个种子、冻结层级与运行时，以及六个操作化谓词。退化的冻结 t 区间 [1,1] 是相同观测下所记录描述惯例的性质；它不是普遍概率置信界，不能被描述为后者。

**论文写作建议。** 写“在 60 次注册尝试中未观察到未授权越权”，或“在 60/60 个测试案例中保持优先级”。紧接着说明测试场景边界。避免“保证权限保持”“可证明安全”或“永远不能越过安全”。

## 建议的论文呈现

- **主文：**紧凑权限表，包含总体 60/60、0 越权、四个场景行和三个风格层。所有单元相同，无需图形。
- **补充材料：**六个谓词定义、适用计数、确定性容差和全部 360 行权限检查。
- **图注边界：**将数值标为注册冲突案例中的观测保持，而非形式证明。

# E4 关于有界行为落地的组合证据

E4 有两个逻辑上必要的部分。

**事实——E4A。** 固定名义参考和高优先级任务/安全量时，改变 smooth/normal/aggressive 风格，在匹配机动三元组中改变了控制努力、加速度峰值/RMS 和跟踪 RMSE。[来源：`E4A-SUMMARY`；`E4A-PAIRS`。]

**事实——E4B。** 在独立权限冲突案例中，全部 60 次尝试保持注册层级，产生零未授权越权。[来源：`E4B-SUMMARY`；`E4B-CHECKS`。]

**解释。** 没有 E4A，风格可能是语义装饰：存在于任务记录，却无物理作用。没有 E4B，风格可能具有行为表达力但不安全或无界。二者共同支持有界主张：**在测试场景中，有界运动风格语义可以调制底层集群行为，而不越过高优先级执行权限。**

该组合不会把 E4B 观测保持变为证明，也不会把 E4A 部分支持的方向排序变为普遍单调性。“有界行为落地”指可测调制加上对注册权限层级的观测从属——不是声称每种可能风格话语或物理情形都安全。

**论文写作建议。** 先呈现 E4A，再呈现 E4B，让读者先看到风格具有真实行为内容，再看到约束机制。使用一句组合结论，并分别保留行为排序与权限泛化的限制。

# 面向审稿人的证据边界

## 1. “延迟绑定只是架构偏好吗？”

**相关证据。** E2 固定语义解释和物理策略栈，在相同场景/种子状态下配对 Early 与 Information-Aligned Late 条件。SHIFT 下，Early 产生 25/30 状态一致性违规和 15/30 不可行/修正结果，Late 两者均为 0/30；NO_SHIFT 下两者均无不良结果。[来源：E2-SUMMARY；E2-ATTEMPTS。]

**已解决。** 特别在所需信息变化时，承诺时机造成可观察差异。无偏移对照和不变的可执行落地率支持信息可用性机制，而非拒绝或无条件 Late 优势。

**未解决。** 检验不确立所有承诺决策的普遍规则。已知且稳定的值可能安全地早期承诺，其他状态变化过程未经测试。

**正确论文边界。** 对所评估重构场景中的状态依赖量，延迟绑定具有实证依据。

## 2. “E1 证明了稳健自然语言理解吗？”

**相关证据。** E1 达到 96/96 精确有效任务准确和 0/225 过早承诺，但只拒绝 19/24 无效命令，包括 0/4 非法过渡，严格格式合规为 0/162。[来源：E1-SCORE。]

**已解决。** 冻结候选接口可表示注册有效命令并保留注册欠指定。

**未解决。** 开放世界语言多样性、注册表外改述稳健性、对抗语言、广泛无效命令拒绝和替代接口比较均未经测试。

**正确论文边界。** 描述冻结候选语义数据集结果，而非一般 NLU 能力。

## 3. “为什么安全不能全部交给规划？”

**相关证据。** C 族中，安全感知规划移除了可预测冲突，但 P1_F0 保留平均 J_hard = 1.3687 pair-s，22/25 区组有任意硬风险；P1_F1 将平均暴露降至 0.3303 pair-s，配对二元风险差为 −0.3600 [−0.4800, −0.2400]。[来源：E3-SUMMARY；E3-CELL；E3-BINARY。]

**已解决。** 一旦执行偏差在规划后发生且不在规划器输入中，正确结构规划可与显著实际残余风险共存。

**未解决。** 实验不表明每个规划器都会留下相同风险，也不表明预测型规划器无法建模其他偏差分布。

**正确论文边界。** 规划负责可预测结构冲突；反馈处理测试规划后偏差检验中的残余执行风险。

## 4. “为什么安全不能全部交给反馈？”

**相关证据。** A 族暴露规划器可见结构冲突。规划对比为 Delta_P(J_hard) = −1.6810 pair-s，95% CI [−1.9786, −1.4690]；P1 还将最小间距增加 1.8288 m、事件减少 2.1087，并在 23 个完整区组中移除二元硬风险发生。预测冲突操纵检查为 −2.0000。[来源：E3-REPORT；E3-FACTORIAL；E3-BINARY。]

**已解决。** 规划时移除可预测冲突产生大且机制对齐的安全效应；在这些场景中，把已知冲突留给执行层在经验上并不等价。

**未解决。** 实验不比较所有可能反馈控制器，也不证明另一配置下反馈永远不能补偿较差计划。

**正确论文边界。** 在注册 A 族场景中，规划是已被证明负责可预测结构风险的职责。

## 5. “规划与反馈只是两个模块放在一起吗？”

**相关证据。** C 族在空间隔离混合风险场景中析因操纵两种职责。J_hard 显示 Delta_P = −1.7116 和 Delta_F = −1.2004 pair-s；P1_F0 暴露残余风险，F1 减少它。连续交互为 +0.3239 [−0.0825, +0.7311]，二元交互为 −0.3600 [−0.4800, −0.2400]。[来源：E3-FACTORIAL；E3-BINARY；E3-CELL。]

**已解决。** 每个因子在共同混合场景中产生注册效应，中间 P1_F0 单元显示两种职责为何都重要。

**未解决。** 未证明因子数学独立。端点阈值化产生不同交互行为，冻结契约不要求非零交互。

**正确论文边界。** 证据支持这些混合场景中的职责分解与近似可加连续暴露效应——不是普遍模块独立。

## 6. “运动风格真的改变行为吗？”

**相关证据。** 在 15 个精确参考三元组中，Aggressive−Smooth 将控制努力增加 0.5676 m/s、逐机加速度峰值均值增加 0.5836 m/s²、加速度 RMS 增加 0.1721 m/s²，三个冻结区间均远离零；跟踪 RMSE 变化 −0.05179 m。[来源：E4A-SUMMARY；交叉核验 E4A-PAIRS。]

**已解决。** 风格标签在所评估机动中有可测底层后果。

**未解决。** 上升时间几乎不变，稳定差较小且区间跨零，不存在普遍 Normal 排序。

**正确论文边界。** 主张行为可区分性，而非普遍有序动态。

## 7. “风格能越过安全或时序吗？”

**相关证据。** E4B 在可行时序、不可行时序、自动时序和活跃安全案例中，观察到 60/60 尝试优先级保持、零未授权越权。[来源：E4B-SUMMARY；E4B-CHECKS。]

**已解决。** 测试风格没有绕过注册权限层级或冻结运动/控制器约束。

**未解决。** 未注册场景、格式错误配置、实现故障和其他风格未被评估。

**正确论文边界。** 风格在测试权限冲突案例中保持从属。

## 8. “60/60 权限保持意味着形式保证吗？”

**相关证据。** 对固定 60 次尝试注册表而言，观测完整，冻结描述比率与区间等于 1.0。[来源：E4B-SUMMARY。]

**已解决。** 此注册表中没有观测违规。

**未解决。** 有限测试不是形式验证。退化 Student-t 区间反映相同观测值，而非关于全部执行的定理。

**正确论文边界。** 报告 60/60 观测保持，并明确否定普遍保证措辞。

## 9. “343/343 任务成功意味着整个实验活动 100% 成功吗？”

**相关证据。** E3-v4 注册并消耗 360 次尝试：343 科学成功、17 基础设施失败。343/343 次科学尝试任务结果可用且成功，但另外 17 次不可用。[来源：E3-COMPLETION；E3-OPERATIONS。]

**已解决。** 每次科学评分尝试均完成注册任务。

**未解决。** 17 个基础设施案例没有科学任务结果，不能悄然赋予成功或失败。

**正确论文边界。** 为 343/343 陈述加上条件，并单独报告 17/360 基础设施失败。

## 10. “E3 测量了反馈干预负担吗？”

**相关证据。** 效应估计前端点裁决检查全部 343 次科学尝试，发现预注册负担端点不可用：N=0/343，proxy used=no。[来源：E3-ENDPOINT。]

**已解决。** 对干预时长、频率或幅度没有任何定量结论；仅测量了所分配 F1 条件的安全效应。

**未解决。** 更安全规划是否减少反馈工作量，以及能否以更少干预获得相当安全性。

**正确论文边界。** 披露观测遗漏，不作反馈努力主张；不要把处理分配或控制器近限比例当作代理。

## E1 提取单元

**A. 一句话目的。** E1 评估冻结候选语义接口是否保留预期任务，同时让状态依赖物理中心、尺度和时序值保持未解析，直到后续运行时阶段。

**B. 两至四句设计。** 封存注册表包含 120 条命令：96 有效、24 无效，有效命令分布于任务结构、中心、尺度、时序、风格、安全、过渡和编队类别。命令使用冻结提供方配置、最多三次解析器尝试，在封存随机推理顺序中评估，保留每次提供方尝试。有效输出按 schema 接受、精确归一化语义相等、字段准确与过早数值承诺评分；无效命令依据不可变拒绝类别评分。[来源：E1-PROTOCOL；E1-REGISTRY；E1-ORDER。]

**C. 关键结果。** 全部 96 条有效命令产生 schema 有效 Candidates，并精确匹配归一化语义真值；每个注册 U/F/c/r/T/m/s/q 任务字段在 120 个任务实例上均正确，任务关系在 96/96 条命令上正确，过早数值承诺为 0/225。无效拒绝为 19/24，其中非法过渡拒绝 0/4、语义矛盾拒绝 3/4。返回响应的严格 JSON 格式合规为 0/162；24/120 条命令至少需要一次重试，产生 163 次提供方尝试，提供方尝试与命令至终态延迟中位数分别为 17,334.520 ms 和 20,962.5 ms。[来源：E1-SCORE；E1-MANIFEST。]

**D. 科学启示。** 在冻结候选数据集上，接口有力保留有效任务语义和注册欠指定，提供延迟绑定落地的语义部分。

**E. 限制。** E1 不是开放世界 NLU、广泛无效命令拒绝、可靠非法过渡拒绝、严格提供方 JSON 行为或延迟承诺物理收益的证据。

## E2 提取单元

**A. 一句话目的。** E2 隔离检验：当状态在解释后变化时，在信息对齐执行快照上承诺未解析物理量是否避免陈旧或不可行行为。

**B. 两至四句设计。** 冻结设计包含 120 次科学完整尝试，构成 60 对 Early/Late，均分为六个场景和五个种子中的 30 对 SHIFT 与 30 对 NO_SHIFT。两种条件接收相同命令和 Candidate 语义；Early 在解析时数值解析 c/r/T，而 Information-Aligned Late 保留未解析字段直到执行时解析。语义字段、每对内状态、策略、分配器、控制器和种子保持固定，注册不良结果为可执行落地、状态不一致、动态不可行、修正和拒绝。[来源：C2-RAW-E2；E2-SUMMARY。]

**C. 关键结果。** SHIFT 下，Early 产生 25/30 状态一致性违规和 15/30 动态不可行/修正结果；Late 两者均为 0/30。冻结 Late−Early 配对效应为状态不一致 −0.8333 [−0.9749, −0.6918]、不可行/修正 −0.5000 [−0.6899, −0.3101]。NO_SHIFT 下两种条件均无不良结果；两种承诺条件可执行落地均为 60/60，拒绝均为 0/60。[来源：E2-SUMMARY；E2-ATTEMPTS；E2-PAIRS。]

**D. 科学启示。** 在测试状态偏移案例中，将承诺推迟到相关执行状态可用时，消除了注册陈旧与可行性修正结果，且优势并非来自拒绝。

**E. 限制。** 结果限于六个确定性离线场景，不确立普遍延迟绑定最优，也不表明所有早期承诺均不合适。

## E3-v4 提取单元

**A. 一句话目的。** E3-v4 测试无人机集群重构中，可预测结构风险和规划后残余执行风险是否由不同规划与反馈职责降低。

**B. 两至四句设计。** 冻结 2×2 析因设计把仅距离与安全感知规划（P0/P1）同反馈避障关闭与 IAPF 开启（F0/F1）交叉，覆盖六个场景：两个可预测风险 A 族场景、两个规划后偏差 B 族场景、两个空间隔离混合风险 C 族场景。每场景十五个种子与四个单元产生 360 次注册尝试和 90 个四单元区组。十七次基础设施失败后剩余 343 科学成功；根据预注册整区组规则，74 个完整区组（296 次尝试）构成主要总体，没有替代或插补。主要端点为 d_hard = 1.50 m 以下的逐对求和硬风险暴露 J_hard。[来源：E3-REGISTRY；E3-CONTRACT；E3-COMPLETION。]

**C. 关键结果。** A 族规划效应 Delta_P(J_hard) = −1.6810 pair-s [−1.9786, −1.4690]，N=23，伴随最小间距 +1.8288 m、事件 −2.1087、任意硬风险 −1.0000。B 族反馈效应 Delta_F(J_hard) = −1.2275 pair-s [−1.3890, −1.0562]，N=26，伴随最小间距 +0.0492 m、事件 −0.7692、任意硬风险 −0.3462。C 族 Delta_P = −1.7116、Delta_F = −1.2004、Delta_PF = +0.3239 pair-s（N=25）；P1_F0 单元保留平均 J_hard = 1.3687，22/25 区组有任意风险，而 P1_F1 平均 J_hard 为 0.3303，P1 内二元风险差为 −0.3600 [−0.4800, −0.2400]。全部 343 次科学评分尝试完成任务，17 次基础设施尝试任务结果不可用，反馈干预负担在 0/343 科学尝试中可用（NA；不可测试）。[来源：E3-REPORT；E3-FACTORIAL；E3-BINARY；E3-CELL；E3-OPERATIONS；E3-ENDPOINT。]

**D. 科学启示。** 确证检验支持测试无人机集群重构场景内的规划–执行安全分解：规划移除可预测冲突，反馈减少规划后引入的实际风险。

**E. 限制。** 推断限于六个固定场景的 74 个完整区组；不假设 MCAR，干预负担不可测试，数据不提供普遍安全、独立、无碰撞或优越性保证。

## E4A 提取单元

**A. 一句话目的。** E4A 确定 smooth、normal 和 aggressive 语义风格是否在相同名义任务与安全参考下产生可区分底层行为。

**B. 两至四句设计。** 四十五次科学完整尝试在水平、垂直和对角 3-D 机动与五个种子中构成 15 个匹配风格三元组。各三元组内固定初始位置、目标、显式时长、安全值、种子及 Minimum-Jerk 参考身份，风格只被允许改变有界执行配置。注册指标涵盖控制努力、加速度峰值/RMS/上升时间、跟踪 RMSE 和稳定时间。[来源：C2-RAW-E4；ANALYSIS-SEMANTICS；E4A-SUMMARY。]

**C. 关键结果。** Aggressive−Smooth 配对差为控制努力 +0.5676 m/s [0.3535, 0.7818]、逐机加速度峰值均值 +0.5836 m/s² [0.4256, 0.7415]、加速度 RMS +0.1721 m/s² [0.1136, 0.2306]、跟踪 RMSE −0.05179 m [−0.06101, −0.04257]，均为 N=15。稳定时间约为 −0.0243 s [−0.0750, 0.0264]，N=13；加速度上升时间为 −0.00445 s [−0.1357, 0.1268]，N=15。Normal 在峰值 13/15、努力 13/15、RMS 11/15、跟踪 15/15 三元组中居中，但上升时间仅 5/15、稳定仅 6/13。[来源：E4A-SUMMARY；交叉核验 E4A-PAIRS。]

**D. 科学启示。** 在共享名义参考下，测试运动风格语义在行为上可区分，尤其体现在控制强度、加速度和跟踪上。

**E. 限制。** E4A 不确立普遍 smooth–normal–aggressive 排序，尤其在上升与稳定行为上，也不测试权限保持。

## E4B 提取单元

**A. 一句话目的。** E4B 测试当显式时序、动态可行性、硬安全、运动限制和控制器权限活跃时，低优先级风格偏好是否保持从属。

**B. 两至四句设计。** 六十次科学完整尝试交叉四个权限冲突场景、五个种子和三种风格。场景测试可行显式时长保持、不可行时长修正、自动时长可行性以及活跃安全案例中的安全归属不变。每次尝试六个注册权限谓词确定未授权越权计数和优先级保持率。[来源：C2-RAW-E4；ANALYSIS-SEMANTICS；E4B-SUMMARY。]

这是追加于冻结 E1–E4 参考报告之后的新总结，不替换任何先前总结，也不修订其主张结论。

| 已确立主张映射 | 实验 | 最终报告保留的证据作用 |
|---|---|---|
| C1：信息对齐的延迟绑定落地 | E1 | 精确有效候选语义与注册未解析量保持，保留无效/格式限制 |
| C1：物理承诺时机 | E2 | 配对状态偏移时机证据；不是语言准确性或普遍延迟绑定最优 |
| C2：规划–执行安全分解 | E3-v4 | 确证规划、反馈和混合风险职责证据，保留完整区组/缺失情况及负担不可用边界 |
| C3 / 次要：有界行为落地 | E4A 和 E4B | 行为可区分性加观测权限保持，不是普遍排序或形式保证 |
| 端到端集成 / 系统完整性 | E5-v1 和 E5-v2，分别处理 | 成功注册集成、保留的不可容许性/前端边界、可行欠指定实现，以及 N=8/12/16 运行 |

机制层结论仍属于 E1–E4。E5 增加了独立评估机制在完整命令到控制流水线中共存的证据，而不是 C1/C2/C3 的新因果支持。因此最终报告将模块化机制证据与有界系统集成证据结合，同时保留负面发现、不可用端点和分开的分母。
